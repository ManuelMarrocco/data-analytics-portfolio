# Data Analytics Portfolio

This repository contains a collection of data analysis projects developed as part of my learning journey in data analytics.

The projects are organized to reflect my progression from foundational analysis to more structured, business-oriented problem solving.

---

## Projects

### 1. CO2 Emissions Analysis
Analysis of global CO2 emissions trends using Python.

Main focus:
- Data cleaning and preprocessing
- Exploratory data analysis
- Identification of emission patterns across countries and time

---

### 2. LA Crimes Analysis
Exploration of crime data in Los Angeles.

Main focus:
- Data quality validation
- Geographic analysis
- Identification of high-crime areas and dominant crime categories

---

### 3. OLIST Delivery Performance Analysis
Analysis of e-commerce delivery performance and its impact on customer satisfaction.

Main focus:
- SQL-based analysis
- Delivery delay investigation
- Relationship between delays and negative reviews
- Business-oriented problem framing

---

## Tools & Technologies

- SQL
- Python (Pandas, NumPy)
- Power BI
- Excel

---

## Notes

This portfolio represents my learning path in data analytics.

The projects were developed at different stages of my training.  
The progression from the CO2 project to the LA Crimes and OLIST projects reflects the skills developed through data analytics, Python, Power BI, and AI fundamentals specializations completed during this period.
